# FULLY-FUNCTIONAL-BLOG-WEBSITE
A full-stack blogging platform built using Node.js, Express, and MongoDB



MyBlog is a complete blogging platform built using Node.js, Express, MongoDB, and EJS.
It allows users to create, edit, delete, and read blog posts through a clean and modern user interface.


Features

->Create, edit, and delete blog posts
->Write blogs using Markdown formatting
->Comment section with like and dislike options
->Light and dark theme support
->Fully responsive layout for all screen sizes
->SEO-friendly blog URLs using slugs
->Automatically sanitized HTML output for safe content


Technologies Used

->Frontend
HTML5, CSS3, and JavaScript
EJS template engine
Responsive design
Flexbox and CSS Grid layouts

->Backend
Node.js
Express.js
Method-Override for PUT/DELETE support
Slugify for clean URLs
Marked for Markdown conversion
DOMPurify to sanitize HTML content

->Database
MongoDB
Mongoose for schema modeling and database operations
